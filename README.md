# GlobalImport S.A. - Proyecto de Comercio Electrónico

## 📋 Descripción General

Sitio web profesional y responsivo para **GlobalImport S.A.**, una empresa especializada en importación y comercio internacional. El proyecto ha sido desarrollado con HTML5, CSS3 y JavaScript vanilla, siguiendo las mejores prácticas de desarrollo moderno.

---

## 🎯 Características Principales

### ✨ Diseño Moderno y Corporativo
- Paleta de colores coherente y profesional
- Tipografías modernas desde Google Fonts (Montserrat y Poppins)
- Animaciones suaves y transiciones elegantes
- Efectos visuales contemporáneos (glassmorphism, gradientes)

### 📱 Completamente Responsive
- **Desktop**: Experiencia optimizada para pantallas grandes
- **Tablet**: Adaptación fluida para dispositivos medianos
- **Mobile**: Interfaz totalmente funcional en celulares
- Menú hamburguesa automático en pantallas pequeñas

### 🌐 Secciones Implementadas

1. **Barra de Navegación (Navbar)**
   - Logo de la empresa con icono
   - Enlaces de navegación (Inicio, Servicios, Contacto)
   - Botón destacado de Registro
   - Menú responsivo con hamburguesa para móviles

2. **Sección Hero**
   - Banner con imagen de fondo y overlay degradado
   - Título principal prominente
   - Subtítulo con eslogan corporativo
   - Botón CTA (Call To Action) atractivo
   - Animaciones de entrada elegantes

3. **Sección de Servicios**
   - Grid responsive con 4 servicios principales:
     - Importación de Electrónica
     - Importación de Indumentaria y Accesorios
     - Importación de Artículos del Hogar
     - Logística y Distribución
   - Tarjetas (cards) con iconos, títulos y descripciones
   - Efectos hover con box-shadow y transformaciones
   - Íconos de FontAwesome

4. **Sección "¿Por Qué Elegirnos?"**
   - 3 puntos clave de la empresa:
     - Confianza
     - Experiencia
     - Variedad de Productos
   - Fondo degradado corporativo
   - Efectos de glassmorphism en las tarjetas

5. **Sección de Contacto**
   - Información de email y teléfono
   - Íconos destacados
   - Enlaces funcionales

6. **Footer**
   - Información de la empresa
   - Copyright 2026
   - Enlaces a redes sociales (Facebook, LinkedIn, Twitter, Instagram)
   - Contacto rápido
   - Información adicional

## 🚀 Características Técnicas

### HTML5
- Semántica correcta con etiquetas semánticas (`<nav>`, `<section>`, `<footer>`, etc.)
- Atributos de accesibilidad (`aria-label`, `title`)
- Estructura clara y bien organizada con comentarios

### CSS3
- **Variables CSS** para fácil mantenimiento de colores y estilos
- **CSS Grid** y **Flexbox** para layouts responsive
- **Media Queries** para adaptación a todos los tamaños
- **Transiciones y Animaciones** suaves
- **Box-shadow** moderno para profundidad
- **Gradientes** lineales y radiales

### JavaScript
- Funcionalidad del menú hamburguesa
- Toggle automático en dispositivos pequeños
- Scroll suave hacia secciones
- Sin dependencias externas

### Librerías Externas
- **FontAwesome 6.4.0**: Para iconos profesionales
- **Google Fonts**: Para tipografías modernas
